# CR-002 — TRS §5.3 toolchain moves Java 17 → Java 21 LTS

- **Status:** **ACCEPTED** — owner ruling at the WP-02 S4b review, 2026-08-19.
- **Raised:** 2026-08-18, PR #15 §3, by the implementing agent.
- **Execution:** **WP-02 slice S5. Not this slice.** Nothing in S4c acts on it.
- **Affected requirements:** TRS §5.3 (pinned toolchain), TRS-CICD-006
- **Affected gate:** **G-06** — blocked on Lazysodium 5.1.0 until this lands.

## Change

TRS §5.3 pins the Java toolchain at 17. It moves to **Java 21 LTS**, so that
Lazysodium **5.2.0** can be adopted.

## Rationale (owner text)

Lazysodium 5.2.0 ships **16 KB page-aligned** native libraries; 5.1.0 does not.
Google Play's 16 KB requirement makes that a **G-06 blocker** on 5.1.0 — an
Android 15 device with 16 KB pages cannot map 5.1.0's `arm64-v8a/libsodium.so`
at all. The library is held at 5.1.0 today only because 5.2.0 ships class-file
65 bytecode, which javac under the Java 17 toolchain refuses outright, so the
alignment fix and the toolchain move arrive together or not at all.

**Direct libsodium JNI remains the recorded fallback** if the toolchain move
proves worse than expected.

## What executing this CR will involve (S5)

- TRS §5.3 toolchain value and `tools/toolchain/toolchain-manifest.json`.
- `gradle/libs.versions.toml`: `lazysodium` 5.1.0 → 5.2.0; the Java 17 pin
  comment at the Checkstyle entry is unrelated and stays (Checkstyle 13.x is a
  separate hold, see below).
- Removal of the narrow `Aligned16KB` lint disable in
  `android-app/app/build.gradle.kts`, with its rationale comment.
- **Checkstyle**: pinned at 12.3.1 because 13.x refuses JVM 17. Java 21 removes
  that constraint, but raising Checkstyle is a separate decision and is not part
  of this CR.
- Re-running the instrumented suite: the binding changes underneath
  `LibsodiumRecoveryCrypto.java`, which is the only file that imports it.

## Status until then

`toolchain-manifest.json` records the hold under `held_back_why`, the
`Aligned16KB` disable carries its reason in the build file, and G-06 stays
`unproven_owner`. Nothing ships in WP-02, so no user is exposed by the interval.
